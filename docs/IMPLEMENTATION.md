# RADSYSTEM implementation plan

Audit: the target is roslesmedia/radsystems-, mounted at /workspace/radsystems-. The work branch is unborn and the repository has no source, manifests, assets, or existing features to preserve.

1. Establish Next.js App Router, TypeScript, local fonts, brand assets, design tokens, and an isolated demo commerce adapter.
2. Build a full-bleed, scroll-driven Three.js camera presentation with a locally authored, separable conceptual model. External Poly Haven access was denied by the environment's network policy; no manufacturer model or exact internal engineering is claimed.
3. Implement public shopping routes, searchable sample inventory, comparison, explicit configurator compatibility rules, browser-persisted cart, and demonstration checkout/account interfaces.
4. Implement an isolated admin design preview with editable sample data and guarded price previews. WooCommerce remains the planned production source of truth.
5. Verify production build, TypeScript, interaction flows, desktop/mobile rendering, WebGL pixels, and reduced motion. Document limitations and deployment prerequisites.

Visual direction: obsidian, graphite, red and silver, Vazirmatn/Manrope, the custom Sentinel R, physically shaded 3D geometry, restrained motion, and unframed editorial sections.
